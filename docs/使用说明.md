# 极速看片 · 使用说明

本文面向最终使用者，介绍从构建安装到日常使用的全部细节。开发者请另阅《架构设计》。

---

## 1. 安装与启动

### 1.1 从源码构建（当前版本唯一获取方式）

准备工作：

1. 安装 **Node.js 18+**（https://nodejs.org）
2. 安装 **Rust 1.77.2+**（https://rustup.rs，Windows 安装时勾选默认 MSVC 工具链）
3. Linux 用户额外安装系统依赖（Debian/Ubuntu）：

   ```bash
   sudo apt-get install libwebkit2gtk-4.1-dev build-essential curl wget file \
     libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
   ```

构建步骤（在项目根目录执行）：

```bash
npm install        # 安装前端依赖（首次约 1~3 分钟）
npm run tauri dev  # 开发模式运行，可直接体验全部功能
npm run tauri build # 打包正式安装包（产物见 src-tauri/target/release/bundle/）
```

- Windows：产物为 `nsis/*.exe` 安装包（或 `msi/*.msi`），双击安装后从开始菜单启动
- macOS：产物为 `*.dmg`，拖入「应用程序」
- Linux：产物为 `.deb` / `.rpm` / `.AppImage`，按发行版习惯安装/直接运行

### 1.2 首次启动

启动后会看到黑色引导界面，两种方式开始观看：

- **点选目录**：点击引导页中央的大号「**+**」按钮，在弹出的系统对话框中选择一个包含视频的文件夹
- **拖拽目录**：把一个包含视频的文件夹拖到窗口任意位置

两种方式完全等效，随你顺手。另外：

- 拖入或选中「文件」时，程序会自动改为打开它所在的文件夹
- 拖入/选中新文件夹随时可以替换当前目录，开始新一轮观看
- 按 `X` 随时关闭当前目录，回到引导页重新选择（该目录的位置记忆同时清除）
- 程序会记住退出时的位置，下次启动定位到该位置并**暂停**，按空格继续

## 2. 界面说明

打开目录后，主界面是一幅**纯黑影院舞台**（画面包含式居中铺满，左上角显示白色文件名），外加几个浮层：

| 区域 / 浮层 | 呼出方式 | 说明 |
|---|---|---|
| 画面舞台（主窗口） | 常驻 | 纯黑背景；画面按原始宽高等比缩放居中；左上角白色文件名与相对目录；支持旋转（90° 步进）、缩放（1×~5×）与放大后的拖拽平移；右下角 HUD 显示当前倍率与角度（非默认时） |
| 文件列表浮层（屏幕右侧） | `T` 切换（默认显示） | 独立于主窗口的右侧浮层（黑色背景、亮灰文字、紧凑小字号）：每个目录的视频文件顺序显示（目录变化处有分组行），正在播放的行高亮（左侧绿条 + ▶ 指示）；有断点的文件右侧显示「已看 mm:ss」徽标；点击浮层底部页码翻页（回车在本程序里是播放 / 暂停）；隐藏后画面自动变宽 |
| 顶部信息栏 | `I` 切换（默认显示） | 窗口顶部一条深色背景、白字：相对目录 / 文件名 · 当前音轨 / 字幕 · 缩放旋转状态（非默认时） · 播放百分比 · 当前时刻 / 总长 · 第几个 / 共几个；随播放动态更新，不拦截鼠标 |
| 底部控制栏 | `C` 切换（默认显示） | 两行式：**最左侧是放大的播放 / 暂停按钮**；右侧上半行靠右依次为上一 / 下一文件、−30s / +30s、**音轨选择（弹出菜单）**、**字幕选择（弹出菜单，含「不启用」）**、旋转、全屏、**音量图标（可点击静音 / 解除）**与音量滑杆；下半行为占满可用宽度的播放位置滑杆（已播部分绿色填充），当前时刻 / 总长文字位于同行最右侧 |
| 帮助层 | `F1` 切换 | 列出全部快捷键与鼠标操作；按任意键或点击空白关闭 |
| 瞬时提示 | 自动出现 | 音轨 / 字幕切换、缩放、播放完毕、自动播放被拦截等状态的短提示，数秒后自动消失 |

## 4. 观看逻辑详解

### 4.1 文件序列是怎么排的

拖入目录后，程序按以下规则把所有视频文件排成一条线：

1. 在每个目录内，**本目录的视频文件排最前**，按文件名「自然排序」（忽略大小写，数字按数值比：`ep2` < `ep10`）；
2. 然后按目录名排序依次进入各子目录，同样规则递归；
3. 没有视频文件的空目录被跳过；
4. 目录符号链接不跟随（避免循环），隐藏文件（以 `.` 开头）不算视频文件；
5. 扫描同时收集各目录的外挂字幕（`.vtt` / `.srt` / `.ass` / `.ssa`），与同目录同前缀的视频自动配对。

示例：拖入 `D:\剧集` 后的实际观看顺序：

```
D:\剧集\00-先导片.mp4          （本目录文件先看）
D:\剧集\第01季\1.mp4           （进入第一个子目录 第01季）
D:\剧集\第01季\2.mp4
D:\剧集\第01季\10.mp4          （自然排序：2 在 10 前面）
D:\剧集\第02季\1.mp4           （第二个子目录 第02季）
...
```

### 4.2 分页与「选中」

- 文件列表按浮层高度自动分页，每页行数 = 浮层高度 ÷ 行高（列表为固定小字号、行高固定 24px）；
- **列表始终选中（高亮）当前播放的文件**；首次打开目录自动选中第一个文件并开始播放；
- 播放文件变化（`PageDown` / 点击行 / 自动连播）后列表自动翻到它所在的页；翻页用浮层底部的页码指示（点击翻页，末页回首页）；
- 有断点记忆的文件右侧显示「已看 mm:ss」徽标，配合 `PageDown` 快速找到没看完的剧集。

### 4.3 手动导航与自动连播

| 行为 | 规则 |
|---|---|
| 手动导航（`PageDown` / `PageUp` / 点击行） | **始终环形**：最后一个的下一个回到第一个，第一个的上一个回到最后一个 |
| 自动连播（一个文件播完之后） | 顺序播放下一个；列表末尾停止并提示「列表播放完毕」 |

### 4.4 音轨

- MP4 家族文件加载时程序只读元数据（moov）分析出全部音轨（语言标签 + 声道数），MKV / WebM 只读头部轨道表（音轨 + 编码名）；
- **多音轨 MP4**：菜单可用，**默认选中界面语言（中文）**，且只在 WebView MSE 支持的编码里挑；
  - **同编码切换**（如双 AAC）：视频画面不中断；
  - **异编码切换**（AAC ⇄ Opus 等）：程序自动重建播放管线后原位恢复（画面会快速重载一下，属正常现象）；
  - WebView 不支持的编码（如 AC-3 / DTS）在菜单里**置灰并标注原因**，不可选；
- **MKV / WebM**：音轨（含编码名）列在菜单里供查看，但 Chromium 原生播放无法运行期切轨，选择时会提示（属 WebView 限制）；
- **单音轨**：音轨按钮自动禁用；
- WebView 完全不支持该文件的编码组合时回退原生播放（单音轨直读），菜单保留但切换受限并提示；
- 上次手动选择的语言会记住，下次打开新文件优先匹配（例如上次选了日语，新文件的默认音轨就是日语轨）。

### 4.5 字幕

字幕菜单统一列出四类来源（「不启用」始终在列）：

| 来源 | 说明 |
|---|---|
| 外挂 `.vtt` | 与视频同目录、同名前缀（`电影.vtt` / `电影.zh.vtt`），直接挂载 |
| 外挂 `.srt` | 同名匹配后自动转换成 WebVTT 再挂载（时间戳逗号→点） |
| 外挂 `.ass` / `.ssa` | 同名匹配后解析为富文本（斜体 / 粗体）挂载；排版特效与绘图指令丢弃 |
| 内嵌字幕（MP4） | MP4 内的 wvtt / tx3g 字幕轨，选择时抽样提取出文本生成字幕（首次选择稍有等待；原生播放模式下超过 4GB 拒绝，建议改用外挂字幕） |
| 内嵌字幕（MKV） | MKV 内的 SRT / ASS 字幕轨，选择时流式提取（分块读盘边读边解析，内存占用恒定、**任意大小文件可用**，状态栏显示百分比，切走即取消）；ASS 同样解析为富文本。耗时只受磁盘速度限制：5GB 约 SSD 数秒 / 机械硬盘数十秒 |
| HLS 字幕轨 | m3u8 清单声明的字幕轨（hls.js 渲染） |

- **默认匹配界面语言**：有中文字幕（外挂或 MSE 模式的 MP4 内嵌）就自动选中，否则「不启用」；MKV 内嵌字幕不自动选中（流式提取要扫全文件，大文件耗时数秒至数十秒，不适合静默自动触发），手动选择不受限；
- 图形字幕（PGS / VOBSub 位图字幕）在菜单中置灰并说明，无法转为文本；
- 文件名语言后缀（`电影.chs.srt` / `电影.en.ass`）会体现在菜单标签里；
- 没有任何字幕流时字幕按钮禁用；
- 上次手动选择的语言同样会被记住。

### 4.6 旋转 / 缩放 / 平移

- `R` 或控制栏「旋转」按钮：每次顺时针 90°（0° → 90° → 180° → 270°）；
- `+` / `-`：缩放步进 0.25×，范围 1×~5×；缩放回 1× 时平移自动归零；
- 放大后（>1×）在画面上**按住拖拽**即可平移，任意旋转角度下拖拽方向都跟手；画面边缘不会被拖出舞台；
- 旋转角度与缩放倍率随状态持久化，下次启动保持；
- 当前倍率 / 角度显示在画面右下角 HUD 与顶部信息栏（非默认时）。

### 4.7 断点续看（每文件记忆）

- 播放过程中程序持续（防抖）记录**每一个文件**的当前位置；切换文件再切回来，自动从上次位置继续；
- 一个文件**播放完毕**，它的断点立即清空（下次从头开始）；
- 距开头不足 1 秒或距末尾不足 1 秒的进度不记忆（视为未看 / 已看完）；
- **退出程序**：记住当前文件与位置，下次启动定位到该位置并**暂停**——按空格从中断处继续（多音轨文件经「关键帧粗定位 + 精确落点」两段恢复到退出帧）；
- 断点、音量、旋转、缩放、音轨 / 字幕语言偏好、各浮层可见性全部随状态文件持久化（静音为临时状态，不持久化）；
- 按 `X` 关闭目录：清除该目录（含子目录）所有文件的断点与恢复指针；**其他目录的断点保留**，之后重新拖入即可继续；
- 彻底重置：删除状态文件（Windows `%APPDATA%\jisu-kanpian\state.json`；macOS `~/Library/Application Support/jisu-kanpian/state.json`；Linux `~/.config/jisu-kanpian/state.json`）。

## 5. 支持的格式一览

- **MP4 家族**（mp4 / m4v / mov）：多音轨走 MSE 播放 + 多音轨 / 内嵌字幕 / 帧率分析
- **Matroska 家族**（mkv / webm）：原生播放 + 音轨 / 字幕轨 / 帧率分析 + 内嵌 SRT/ASS 字幕提取（流式，无大小限制）
- **HLS**（m3u8 及其分片目录）：hls.js 播放（音轨 / 字幕轨按清单）
- **开放格式**（ogv / ogg）：原生播放
- **尽力播放**（avi / 3gp）：取决于系统 WebView 解码器

外挂字幕：`.vtt` 直接挂载，`.srt` 自动转换，`.ass` / `.ssa` 解析为富文本。大小写不敏感（`.MP4` 与 `.mp4` 等价）。

## 6. 故障排查

| 现象 | 原因与处理 |
|---|---|
| 某个文件提示「无法播放」 | 该格式当前系统 WebView 不支持（常见于部分平台的 mkv / avi 封装）。转换格式或换文件；其余文件不受影响 |
| 多音轨菜单显示但切换提示受限 | WebView 的 MSE 不支持该编码组合，已回退原生播放（Chromium 系 `<video>` 无音轨选择 API） |
| 内嵌字幕选了没反应 | 该字幕轨是 v1 暂不支持的编码（支持 wvtt / tx3g），或轨内没有可显示内容；换外挂字幕不受影响 |
| 提示「文件超过 4GB，暂不支持 MP4 内嵌字幕提取」 | 仅 MP4 原生播放模式有此限（mp4box 提取需整文件驻留内存）；改用外挂 .srt/.ass，或 MKV 文件（流式提取无大小限制） |
| m3u8 无法播放 | 检查分片是否与清单同目录、路径可读；程序会提示 HLS 具体错误 |
| 启动后自动播放被拦截 | 系统自动播放策略所致。按空格即可开始 |
| Linux 上 `npm run tauri dev` 报 `webkit2gtk-4.1 not found` | 未装系统依赖，见 1.1 节的 apt 命令 |
| Windows 构建报链接错误 | 未装 MSVC Build Tools，安装 VS 的 "Desktop development with C++" |
| 想清除观看记录 | 按 `X` 关闭目录即可（只清当前目录）；彻底清除删除 4.7 节的状态文件 |
| 快进后落点有少量偏差 | 多音轨文件先落关键帧再自动精调（两段式）；若精调被后续操作取消会停在关键帧，通常相差不超过几秒 |
| 点「+」没弹出目录对话框 | 取消选择不会做任何事，重试即可；若始终无法弹出，重新执行 `npm install` 并确认 `tauri-plugin-dialog` 已随项目编译 |

## 7. 小技巧

- **追剧**：断点记忆按文件保存，`PageDown` 配合「已看 mm:ss」徽标快速跳到没看完的剧集
- **外语学习**：多音轨 + 双语字幕（内嵌 / 外挂混选），`,` `.` 逐帧跟读，`←` `→` 大步回放
- **竖拍的手机视频**：`R` 旋转 90° 一次搞定；旋转和缩放都会被记住
- **看画面细节**：`+` 放大后拖拽平移，`-` 逐步收回；HUD 实时显示倍率
- **误拖了文件？** 没关系，程序会自动打开它所在的文件夹
- **不习惯拖拽？** 引导页「+」按钮点选目录，效果一样；空目录/出错页面也有同款按钮，换个目录不用重拖
- **想要画面占满全宽？** 按 `T` 收起右侧文件列表浮层即可
- **沉浸观影**：双击画面全屏即纯画面模式——顶栏、底栏与文件列表浮层立即全部隐藏，屏幕上只留视频画面（键盘 / 滚轮照常可用，退出全屏后浮层按 I / C / T 偏好恢复）；播放期间自动阻止系统屏保与休眠；`I` `C` `T` 手动收起信息栏 / 控制栏 / 文件列表；`F1` 随时唤回快捷键表
