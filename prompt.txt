参考 https://github.com/hootoovv/jisu-tingshu 的技术栈，编码风格，程序首页风格，文档风格，甚至界面布局和功能，仿照实现一个：极速看片的软件。要求：
使用与极速听书相同的布局：主窗口，顶部信息栏，底部控制栏，文件列表窗口等。
控制栏中提供：播放 / 暂停，快进 / 快退（30秒），音量与静音，以上三个与极速听书相同。删除：随机 / 顺序 和 循环三态 按钮，替换为：上一文件 / 下一文件，音轨选择（弹出式菜单选项，默认选中界面语言，其他选项从文件内容中获取全部音轨信息，只有一个音轨时，此按钮禁用），字幕选择（弹出式菜单选项，默认匹配界面语言，提供不启用选项，其他选项从文件内容中获取字幕流信息，没有字幕流时，此按钮禁用），旋转（每次顺时针旋转90度），全屏按钮。
提供画面放大缩小功能，放大后可拖拽鼠标来移动可见的视频画面。

提供如下快捷键：
右键：快进（30秒）
左键：快退（30秒）
上键：音量+5%
下键：音量-5%
空格：播放\暂停
回车：播放\暂停
PageDown：下一文件
PageUp：上一文件
Home：文件开始
End：文件结束
ESC：全屏时退出全屏，非全屏时退出程序
+：画面放大
-：画面缩小
,（含中文逗号）：退后一帧
.（含中文句号）：前进一帧
r：顺时针旋转视频画面90度
x：关闭当前文件或目录，回到引导页（同时清除位置记忆）
I：显示 / 隐藏顶部信息栏（默认显示）
C：显示 / 隐藏底部控制栏（默认显示）
T：显示 / 隐藏右侧文件列表浮层（默认显示）
F1：显示所有快捷键

提供如下鼠标操作：
鼠标单击：播放/暂停
鼠标双击：全屏/恢复
鼠标滚轮向上滚动：音量+5%
鼠标滚轮向上滚动：音量-5%

程序退出时可以记住上次观看的文件和位置，下次启动时跳转到上次退出的位置，暂停播放。程序需要记住所有配置项。

实现时使用Video标签+HLS.js播放视频，使用mp4box.js + MSE实现多音轨支持，使用WebVTT实现外挂字幕。
支持所有Webview的Video标签支持的文件格式即可。

━━ 实现说明（与原文的差异，均为按常理的修正 / 补充，详见 README「功能特性」与《使用说明》《架构设计》） ━━

1. 仓库地址勘误：需求原文的 https://github.com/hootoovv/jisu-tingsu 实为 jisu-tingshu（少一个 h），
   已按正确仓库克隆研究；其技术栈（Rust + Tauri 2 + Svelte 5 runes + Vite 6）、黑色主题、
   两行式控制栏、右侧文件列表浮层、状态文件路径规范、README / 使用说明 / 架构设计三件套
   文档结构与本 prompt.txt 的记录惯例全部沿用；
2. 鼠标「滚轮向下滚动：音量-5%」原文两行均写「向上」，按常理实现为向下减音量（与参考项目一致的修正）；
3. 「右键 / 左键 / 上键 / 下键」按方向键实现（与参考项目的快捷键语义一致）；
4. 「文件开始 / 文件结束」按当前文件内 seek 实现（区别于参考项目的「第一个 / 最后一个文件」，
   按本需求字面语义）；End 跳到文件末尾后若触发 ended，按顺序连播规则前进到下一文件；
5. 鼠标单击细化为：点击文件列表行 = 播放该文件，点击画面 = 播放/暂停（单击与双击用 260ms
   计时器区分），放大后的拖拽不触发单击；参考项目没有双击全屏，本需求新增；
6. 翻页：回车在本程序中是播放/暂停（不再兼任翻页键），文件列表翻页改为点击浮层底部页码指示
   （环形翻页），列表仍始终锚定当前播放文件；
7. 自动连播：删除了随机 / 循环按钮后，一个文件播完按顺序前进，列表末尾停止并提示
   （对应参考项目「不循环」的默认行为；手动导航 PageUp/PageDown 始终环形，与参考项目一致）；
8. 音轨默认选中「界面语言」：无中文轨时回退第一条轨；上次手动选择的语言作为偏好持久化，
   打开新文件时优先匹配偏好（「记住所有配置项」的引申）；
9. 字幕默认「匹配界面语言」：有中文字幕（外挂优先、内嵌限 MSE 模式）自动选中，无匹配则
   「不启用」；没有字幕流时按钮禁用（需求原文语义）；
10. 外挂字幕按「同名前缀 + 语言后缀」与视频配对（电影.zh.vtt / 电影.en.srt），
    .srt 自动转 WebVTT 挂载；内嵌字幕支持 wvtt / tx3g 两种编码（mp4box 抽样提取转 VTT），
    其他编码 v1 暂不支持并在文档说明；
11. HLS：本地 .m3u8 及其分片目录；asset 协议路径整体编码导致 hls.js 相对分片解析失效，
    前端拿到清单后按文件系统路径重写为绝对 asset URL（详见架构设计 3.3）；
12. 多音轨 MP4 走 mp4box.js + MSE 双 SourceBuffer（切换音轨画面不中断），设计取舍是整文件
    读入内存（数百 MB~2GB 可用，文档已说明）；MSE 不可用 / 编码不支持时自动回退原生
    <video> 播放（单音轨），不阻断使用；
13. 逐帧步进的帧率：轨道分析值 → requestVideoFrameCallback 实测值 → 兜底 30fps；
    MSE 文件在已缓冲区直接精确落点，出缓冲区跳转走「关键帧粗定位 + 缓冲就绪精调」两段式
    （断点恢复因此能落回退出帧，与原生文件行为一致）；
14. 「记住所有配置项」：音量、旋转角度、缩放倍率、音轨 / 字幕语言偏好、三个浮层可见性、
    每文件断点、退出恢复指针全部持久化；平移偏移与静音为临时状态（与参考项目静音处理一致）；
15. 验证：npm run build 零警告（142 模块）；mock Tauri API 的无头浏览器冒烟测试 40/40
    断言通过（ffmpeg 生成的真实多音轨 / 内嵌字幕 / HLS / WebM 测试媒体），先后抓获并修复
    六个真实缺陷（详见架构设计第 6 节）；Rust 侧与极速听书同构，请在目标平台 cargo test
    与 npm run tauri dev 复验完整 GUI 链路。
